# Expense Tracker

A simple browser-based expense tracker for recording income and expenses. View your transaction history and see your income, expenses, and balance update automatically.

<img width="1111" height="579" alt="image" src="https://github.com/user-attachments/assets/8f887fcb-85aa-4a14-85f4-c077b6701e12" />

## Features

- Add income and expense transactions with a name, amount, and date
- View all transactions in one list
- See your total income, expenses, and balance
- Delete individual transactions
- Reset all transactions after confirmation
- Save transactions in your browser using local storage

## Getting Started

1. Download or clone this repository.
2. Open `index.html` in your web browser.
3. Add a transaction using the form.

No installation or build tools are required.
